Token Radar (radar-3): every pre-token protocol in the DefiLlama snapshot ranked by an implied value derived from its own figures — 289 rows (103 at/above the $50M floor, 186 early rows below it, all 40 house-watchlist slugs covered), with a per-protocol farm plan, a Live tab for the 40 largest already-trading tokens, pins and side-by-side compare, a command palette, CSV export, a model sandbox that re-ranks the board live, and hash state for deep links. Already-traded products (exchanges, bridges, staking wrappers, versioned pools) stay on the board for coverage but are discounted to the bottom, so the top ranks are genuine pre-token launches.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
